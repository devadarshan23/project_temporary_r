The demo marking, and the reset clock

A sandbox is marked demo in the chrome and on every export so a screen-shared window is never mistaken for a live tenant. Neither exists yet: there is no tenant class carrying a demo flag, no monthly reset job, and no purge that reaches uploaded documents. Uploads are the sharp edge — a prospect's sample invoice sitting in a partner's AWS account after the demo is over is the failure this pane is designed to prevent, and today only the words prevent it.

Specified here for the first time. A sandbox tenant needs: a demo flag, a seed version, a reset cycle with a next-run time, an upload ledger with a purge at reset, source connection and delivery both barred, and usage metered to the partner's wholesale card.
